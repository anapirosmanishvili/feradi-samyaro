# ფერადი კურდღელი 🎨

გასაფერადებელი აპლიკაცია ბავშვებისთვის. ტელეფონზე თითით ან კომპიუტერზე მაუსით აფერადებ.

ნახატები ანა ფიროსმანიშვილის ორიგინალური ნახატების მიხედვითაა შექმნილი.

## გვერდები

- **კურდღელი** ბუშტით, მზით და ყვავილებით
- **ზვიგენი** ზღვაში, თევზებით და ბუშტუკებით

## როგორ მუშაობს

- აირჩიე ფერი და შეეხე სურათის რომელიმე ნაწილს
- 🌈 ჯადოსნური ფერი: ყოველ შეხებაზე ახალი ფერი
- უკან დაბრუნება, საშლელი, „თავიდან“ და „ნახატი“ (ორიგინალი ნახატის ჩვენება)
- გაფერადება ბრაუზერში ინახება

## გაშვება

ყველაფერი ერთ ფაილშია: `index.html`. საკმარისია ბრაუზერში გახსნა.
